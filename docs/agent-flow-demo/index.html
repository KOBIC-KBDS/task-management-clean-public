메시지가 들어오면
어떻게 처리되는지 보여줍니다

Slack 메시지가 수신된 뒤 정규화, 오케스트레이션, 의미 해석, 정책 검증, 로컬 상태 반영, 출력 표면 갱신까지 이어지는 흐름을 단계별로 확인합니다. 화면에는 최종 사용자가 이해해야 할 처리 흐름만 노출합니다.

흐름 읽는 법
  1. 현재 단계가 진하게 강조됩니다
  2. 다음 단계로 향하는 엣지만 움직입니다
  3. 오른쪽 패널에서 현재 입력과 결과를 봅니다
  4. 재생/다음 버튼으로 전체 경로를 확인합니다
내부 생성 표기는 숨기고, 사용자는 처리 결과와 연결 관계만 봅니다.

Standalone public demo: clone the repository and open this file locally to play through the Slack message processing path. No tokens, workspace identifiers, local state, or external network calls are embedded.
