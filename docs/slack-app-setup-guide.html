Task Management 설정 가이드

Slack App 설정 가이드

새 Slack workspace에 task-management용 Slack app을 만들고 토큰을 발급받아 로컬에 연결하는 과정을, 화면 캡처와 함께 한 단계씩 안내합니다.

목표 구성: Socket Mode + App Home DM 소요: 약 15분 최종 산출물: 토큰·ID 4개

전체 흐름

Slack App 생성 → 토큰·Scope·이벤트 설정 → 값 4개 확보 → .env.local.md 입력 → doctor 검증 ✅
★

먼저 — 최종적으로 모을 값 4개

아래 4개를 모으는 것이 이 가이드의 목표입니다. 설정이 끝나면 .env.local.md에 입력합니다.

SLACK_APP_TOKENxapp- 로 시작 — 2단계(App-Level Token) 캡처에서 확보
SLACK_BOT_TOKENxoxb- 로 시작 — 6단계(Install) 캡처에서 확보
SLACK_USER_IDU…/W… — Slack 프로필 → Copy member ID (캡처 아님)
SLACK_DM_CHANNEL_IDD… — 처음엔 비워두고 slack-doctor --live-open-dm이 자동 resolve
⚠️ 토큰이 보이는 캡처 주의
2단계(App-Level Token)·6단계(Bot Token) 화면 캡처에는 실제 토큰이 찍힙니다. 가이드/저장소에 넣을 땐 토큰 부분을 가린 캡처를 쓰고, 토큰 값은 절대 git·문서·채팅에 붙여넣지 마세요. 노출 시 Slack에서 즉시 rotate/reinstall 하세요.
⚙
Slack App 설정 단계
권장 시작점은 Socket Mode + App Home DM입니다. 외부 HTTPS URL 없이 로컬 노드에서 WebSocket으로 Slack 이벤트를 받습니다. 채널 감시는 DM 데모가 안정화된 뒤 켜는 선택 기능입니다.
1

Slack App 생성

위치: https://api.slack.com/apps
1

Create New App → From scratch를 선택합니다.

2

앱 이름(예: Task Management Demo)을 정하고 설치할 workspace를 선택합니다.

📸캡처 자리 docs/screenshots/slack-app-settings/00-create-app.png
✅ 체크포인트
좌측 메뉴에 Basic Information / App Home / OAuth & Permissions / Socket Mode / Event Subscriptions가 보이면 성공입니다.
2

App-Level Token 생성

위치: Settings > Basic Information → 맨 아래 App-Level Tokens

2-1. App-Level Tokens → Generate Token and Scopes

Basic Information 페이지를 아래로 내려 App-Level Tokens 섹션에서 Generate Token and Scopes를 누릅니다.

📸캡처 자리 docs/screenshots/slack-app-settings/01-app-token-1-generate.png

2-2. 토큰 이름 + connections:write scope 추가

토큰 이름(예: task-management-socket)을 입력하고, Add Scope로 connections:write를 추가한 뒤 Generate를 누릅니다.

📸캡처 자리 docs/screenshots/slack-app-settings/01-app-token-2-scope.png

2-3. 토큰 복사 (xapp-)

생성된 토큰을 Copy로 복사합니다. xapp- 로 시작하며, 이 값이 SLACK_APP_TOKEN입니다.

📸캡처 자리 (토큰 부분 가리기) docs/screenshots/slack-app-settings/01-app-token-3-copy.png
SLACK_APP_TOKEN2-3에서 복사한 xapp-… 토큰
3

Socket Mode 활성화

위치: Settings > Socket Mode
1

Enable Socket Mode를 켭니다.

2

토큰을 요구하면 2단계에서 만든 connections:write 토큰을 사용하고 저장합니다.

📸캡처 자리 docs/screenshots/slack-app-settings/02-socket-mode.png
ℹ️ 참고
Socket Mode가 켜져 있으면 Event Subscriptions에서 Request URL(외부 HTTPS)을 넣지 않아도 됩니다.
4

OAuth & Permissions — Bot Scope

위치: Features > OAuth & Permissions → Bot Token Scopes
ℹ️ App Home보다 먼저
다음 단계(App Home)의 Home/Messages 탭은 bot scope가 정의돼 있어야 켤 수 있습니다. 그래서 scope를 먼저 추가합니다.

DM 중심 데모에 필요한 필수 bot scope:

Scope이유
chat:writeDM·확인·브리핑 메시지를 보냅니다.
im:historyapp DM의 message.im 이벤트와 DM history를 읽습니다.
im:write사용자와 app 사이 DM channel을 엽니다.
✅ clean repo 기준
이 3개는 코드의 SLACK_PERSONAL_DM_BOT_SCOPES로 고정돼 있고, slack-doctor가 required_bot_scopes로 자동 검증합니다. DM 데모는 더도 덜도 없이 이 3개면 충분합니다.
⚠️ User Token Scopes는 비워두기
같은 페이지의 User Token Scopes 섹션은 추가하지 않습니다. 이 어댑터는 bot token(xoxb-)만 사용하며, user token(xoxp-)을 넣으면 slack-doctor가 "must be a bot token"으로 거부합니다. SLACK_USER_ID는 토큰이 아니라 DM 상대(사람)를 식별하는 ID입니다.
📸캡처 자리 docs/screenshots/slack-app-settings/03-oauth-required-scopes.png
ℹ️ 채널 감시는 선택
채널 triage를 할 때만 app_mentions:read / channels:history / groups:history를 추가합니다. 처음엔 DM path만 검증하세요.

User ID & DM Channel ID 확보

SLACK_USER_ID — 본인 멤버 ID (U…/W…)

Slack에서 본인 프로필을 열고 ⋮ → 멤버 ID 복사를 누릅니다.

📸캡처 자리 docs/screenshots/slack-app-settings/09-slack-user-id.png

SLACK_DM_CHANNEL_ID — 봇과의 1:1 DM 채널 (D…)

⚠️ 공개/비공개 채널이 아닙니다
여기 필요한 건 나와 봇(Task Management) 사이의 DM 채널 ID로 D로 시작합니다. 공개 채널(C…)이나 비공개 채널(G…)의 ID가 아닙니다.
✅ 가장 쉬운 방법 — 직접 안 찾아도 됨
SLACK_USER_ID만 채워 두고 doctor를 돌리면 DM 채널이 자동으로 잡힙니다. 출력의 dm_resolution에 나온 D… 값을 SLACK_DM_CHANNEL_ID에 고정하거나, 비워둔 채 매번 자동 resolve 하게 둬도 됩니다.
python -X utf8 -m task_management.cli --state .task-management-demo slack-doctor --live-open-dm

수동으로 찾으려면 Slack에서 봇(Task Management)과의 DM을 열고 채널 정보에서 D… 채널 ID를 확인합니다. — #소셜 채널 정보에서 C…를 보신 것과 같은 위치이지만, 대상이 봇과의 DM이어야 합니다.

📸캡처 자리 docs/screenshots/slack-app-settings/10-slack-dm-channel-id.png
⚠️ 캡처 속 ID 노출 주의
이 화면에는 실제 채널 ID(D…)와 봇 멤버 ID(U…)가 보입니다. 토큰만큼 치명적이지는 않지만, 공개 저장소에 올릴 때는 가리는 것이 안전합니다.

설정 검증 — 로컬 doctor

repo 루트에서 아래를 실행합니다. CLI가 .env.local과 .env.local.md를 자동 로드합니다.

1) 로컬 설정 파일 만들기

Copy-Item .env.example .env.local
Copy-Item ops/local_env_markdown_template.md .env.local.md

.env.local.md에 위 4개 값을 입력합니다. 인스턴스 가드는 두 값을 동일하게 두면 어디서든 동작합니다:

SLACK_BOT_TOKEN=
SLACK_APP_TOKEN=
SLACK_USER_ID=
SLACK_DM_CHANNEL_ID=
TASK_MANAGEMENT_INSTANCE_ID=clean-demo
TASK_MANAGEMENT_ALLOWED_INSTANCE_ID=clean-demo

2) DM / Web API 설정 확인

python -X utf8 -m task_management.cli --state .task-management-demo slack-doctor --live-open-dm

3) Socket Mode 설정 확인

python -X utf8 -m task_management.cli --state .task-management-demo slack-socket-doctor
🎉
두 doctor가 모두 통과하면 준비 완료
이후 slack-fast-cycle 또는 slack-socket-loop에 --send를 붙여 라이브로 실행할 수 있습니다.
☑

최종 체크리스트

  • App-Level Token이 있고 connections:write scope를 가진다.
  • SLACK_APP_TOKEN이 xapp-로 시작한다.
  • Socket Mode가 enabled 상태다.
  • Bot Token Scopes에 chat:write, im:history, im:write가 있다.
  • Event Subscriptions에 message.im이 있다. (Home tab이면 app_home_opened도)
  • App Home에서 Messages tab이 켜져 있다.
  • app을 install/reinstall 했다.
  • SLACK_BOT_TOKEN이 xoxb-로 시작한다.
  • SLACK_USER_ID가 본인 id(U…/W…)다.
  • slack-doctor --live-open-dm과 slack-socket-doctor가 성공한다.
  • 토큰·DB·JSONL·Slack transcript를 git에 넣지 않았다.
?

Troubleshooting

SLACK_APP_TOKEN is required
App-Level Token을 만들고 .env.local에 SLACK_APP_TOKEN=xapp-…를 넣었는지 확인합니다.
SLACK_BOT_TOKEN must be a bot token
OAuth & Permissions의 Bot User OAuth Token(xoxb-)을 복사했는지 확인합니다. user token이 아닙니다.
Socket Mode는 연결되는데 DM이 안 들어옴
Event Subscriptions에 message.im이 있고, 추가 후 app을 reinstall했는지 확인합니다.
app에 DM을 보낼 수 없음
App Home의 Messages tab / "사용자가 메시지 보내기 허용" 설정을 켰는지 확인합니다.
conversations.open이 DM을 못 찾음
SLACK_USER_ID를 본인 U… id로 설정하거나, SLACK_DM_CHANNEL_ID=D…를 직접 지정합니다.
토큰을 실수로 문서·채팅에 붙여넣음
즉시 Slack app에서 토큰을 rotate/reinstall하고, 붙여넣은 문서·히스토리에서 제거합니다.
